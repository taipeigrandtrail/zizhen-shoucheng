# 字陣守城 v0.1

這是「漢字合成＋自動塔防」的第一個可玩原型。現階段只驗證核心玩法，不使用其他遊戲的圖片、音效或程式碼。

## 遊戲操作

1. 按「刷新口袋」，花費 10 個饅頭取得 5 個文字或道具。
2. 把口袋文字拖到上窄下寬的 24 格戰鬥場地，或先點文字再點戰鬥格部署；拖到不同文字上會互換位置，原戰鬥棋子回到該口袋格。開局中央有 6 格可用，戰鬥棋子也能拖回口袋。
3. 把鏟子拖到鎖定格，可以永久開放新格子。
4. 口袋可先後點選或拖曳相同文字、相同星級進行合體；戰鬥場可拖曳合體，最高 5 星；點擊戰鬥文字可查看屬性。
5. 弓會射出箭矢、槍會前刺收回、刀會斜劈、騎會旋轉造成範圍攻擊；撐過 10 波即獲勝。
6. 「趙＋雲、關＋羽、黃＋忠」上下或左右相鄰可組成雙格武將，啟動被動加成與專屬技能；必須用另一組同名、同星武將合體升級，拖走其中一字即可拆陣。

## 如何開啟

1. 下載 Godot 4.7.1 stable 的 Windows 標準版。
2. 解壓縮後執行 Godot。
3. 按「匯入」，選擇本資料夾內的 `project.godot`。
4. 進入專案後，按右上角播放按鈕或鍵盤 `F6`。

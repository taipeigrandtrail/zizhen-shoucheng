# 字陣守城 v0.1

這是「漢字合成＋自動塔防」的第一個可玩原型。現階段只驗證核心玩法，不使用其他遊戲的圖片、音效或程式碼。

## 遊戲操作

1. 開始前可選擇金、木、水、火、土五張地圖；每張有獨立美術、28～31 格路線與 24 個文字格。開場 6 格皆成對相鄰，完整地圖也不會出現孤立單格。
2. 按「刷新口袋」，花費 10 個軍餉取得 5 個文字或道具；擊殺敵軍及守住整波都能獲得軍餉，沒有被動補給。
3. 把口袋文字拖到 24 格戰鬥場地，或先點文字再點戰鬥格部署；拖到不同文字上會互換位置，戰鬥棋子也能拖回口袋。戰鬥文字單點顯示攻擊範圍，快速再點一次才會開啟詳細資料。
4. 把鏟子拖到鎖定格，可以永久開放新格子。
5. 口袋可先後點選或拖曳相同文字、相同星級進行合體；戰鬥場可拖曳合體，最高 5 星；單點戰鬥文字看攻擊範圍，雙點查看詳細屬性。
6. 弓會射出箭矢、槍會前刺收回、刀會斜劈、騎會旋轉造成範圍攻擊；撐過 10 波即獲勝。
7. 「關羽、張飛、趙雲、馬超、黃忠」的兩個姓名文字上下或左右相鄰可組成雙格武將；技能固定顯示在五格快捷列，武將未合體時維持沉睡。

## 如何開啟

1. 下載 Godot 4.7.1 stable 的 Windows 標準版。
2. 解壓縮後執行 Godot。
3. 按「匯入」，選擇本資料夾內的 `project.godot`。
4. 進入專案後，按右上角播放按鈕或鍵盤 `F6`。

## iPhone 公開試玩版（GitHub Pages）

- 網址：<https://taipeigrandtrail.github.io/zizhen-shoucheng/>
- 以 Safari 開啟即可，不必與開發電腦連接同一個 Wi-Fi。
- 手機可按住拖曳；口袋文字也能先點選、再點戰鬥格部署。單點戰鬥文字顯示攻擊範圍，雙點查看完整屬性。
- 這是公開網址，任何取得連結的人都能試玩；遊戲不蒐集個人資料。
